# Interactive dashboard

**[Open the live dashboard](https://humpheryeloke.github.io/-tirzepatide-faers-signal-detection/dashboard/)** (opens in your browser, no download needed)

Four pages: Overview, Hidden-signal explorer, Event drill-through, and Method & caveats. Every figure comes from the result files in `outputs/`.

`index.html` is the dashboard itself. It is a single self-contained file, so it also works if you download it and open it in a browser.
